# 救救我的通知！v1.0.0

发布日期：2026-09-05

## 这是什么

“救救我的通知！”是一个本地优先的 Android 通知记录器，用来保存容易被误划掉的通知，并在 Android 仍提供有效动作时尝试返回原内容。应用默认不联网、不上传通知内容，也不提供已读/未读待办体系。

## v1 功能

- 监听并在本机保存未被策略排除的通知，合并同一系统通知的更新，避免制造重复条目。
- 使用稳定时间线展示历史；连续同来源通知合并为默认展开的应用抽屉，跨来源分组时间窗可在设置中调整。
- 从历史记录尝试打开原通知内容；当前没有动作的记录进入独立归档，并可触发一次受限的活动通知重扫。
- 提供按来源查看、仅查看某来源、不查看某来源，以及停止/恢复记录某来源的独立控制。
- 可分别控制媒体、消息与通话、提醒与导航、持续运行与进度及其他通知类型；媒体通知默认不记录。
- 常驻状态通知展示监听健康与最近记录摘要；应用内蓝色实线表示已确认运行，黄色虚线表示未确认运行。
- 支持逐条永久删除记录；删除不会改变该来源的后续监控设置。

## 平台与隐私

- 仅支持 Android 16 及以上。
- `applicationId`：`io.github.prince_dulb.ohmynotification`
- 无网络权限、无遥测、无远程账号。
- 通知内容、运行时动作和应用设置只保存在设备本地。
- 开源许可证：GPL-3.0-or-later。

## 已知边界

- “尝试打开原内容”依赖来源应用创建的 Android `PendingIntent`。来源应用可以取消动作，进程重建后也不保证能够恢复；OMN 不伪造落页成功。
- 归档重扫只检查系统当前仍活动的通知；找不到同一条记录时不会退化为打开来源应用首页。
- 蓝黄健康轨表达的是已获得证据与未获得证据的时间段，不把缺少证据虚构成确定停机。
- v1 已经过红魔 11 Pro+ / Android 16 日用确认；B 站通知类型逐项矩阵、长待机量化、工作资料和万级历史性能仍属于后续补充证据。
